# DriveFlow API

DriveFlow is a car rental Web API built with ASP.NET Core 8.

## Features

- JWT Authentication
- ASP.NET Identity
- Car Management
- Booking System
- Reviews System
- Admin Dashboard
- Role-based Authorization
- Entity Framework Core
- SQL Server Database
- Swagger API Documentation

## Technologies

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- ASP.NET Identity
- JWT Authentication
- Swagger
- NUnit

- DriveFlow.Api
- DriveFlow.Core
