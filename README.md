# DriveFlow API

Final exam project for ASP.NET MVC / Web API course.

## Topic

DriveFlow is a car rental Web API. Users can browse cars, create bookings, manage their own bookings, and administrators can manage cars, categories, users and system data.

## Main Technologies

- ASP.NET Core 8.0 Web API
- Entity Framework Core
- Microsoft SQL Server
- ASP.NET Core Identity
- JWT Authentication
- NUnit
- Swagger
- Fetch demo frontend

## Projects

- `DriveFlow.Api` - controllers and API configuration
- `DriveFlow.Core` - DTOs, service interfaces, service implementations, constants
- `DriveFlow.Infrastructure` - EF Core entities, DbContext, seed data
- `DriveFlow.Tests` - unit tests
- `FrontendDemo` - simple HTML/JS demo using fetch
